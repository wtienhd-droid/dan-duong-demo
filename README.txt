BẢN HTTPS - DẪN ĐƯỜNG DEMO

Cách nhanh nhất:
1. Tạo repository GitHub mới, ví dụ: dan-duong-demo
2. Upload toàn bộ nội dung thư mục này lên repository.
3. Vào Settings > Pages.
4. Ở phần Build and deployment, chọn GitHub Actions.
5. Push/commit lên nhánh main.
6. GitHub sẽ cấp một đường link HTTPS dạng:
   https://TEN-TAI-KHOAN.github.io/dan-duong-demo/

Mở đường link trên điện thoại và cho phép quyền Vị trí.

Lưu ý:
- Tôi không thể tự tạo một URL HTTPS công khai mang tên tài khoản của bạn nếu chưa có quyền truy cập hosting/GitHub của bạn.
- Bản demo dùng OpenStreetMap, Nominatim và OSRM; cần Internet.
